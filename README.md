# 右键长按联动器（RMBCK）

按住鼠标右键超过设定的检测时间后，自动触发你勾选的键盘键位。

## 使用
1. **双击 `RMBCK <版本号>.exe` 即可运行**
2. 首次运行若出现"已保护你的电脑"提示，点「更多信息」→「仍要运行」
3. 程序**需要管理员权限**：启动会弹出 UAC 授权框，点「是」（用于向管理员权限运行的进程注入按键）
4. 要求 Windows 10（1903+）或 Windows 11
5. **全局热键默认 Ctrl+F12**：随时切换联动开关（游戏内也生效），可在「设置」页重新捕获；关闭窗口默认最小化到托盘，退出请用托盘图标右键菜单
6. **需要 Microsoft Edge WebView2 运行时**（Windows 10/11 通常已随 Edge 安装；若提示缺失，按弹窗指引前往微软官网安装）

### 联动目标进程（可选）
在「进程」页选择某个进程：选中后**仅当该游戏窗口在前台时**才触发联动，避免在桌面/其他程序误触发；点「清除限制」恢复不限制

## 配置
界面为左侧导航的五页结构：**概览 / 按键 / 进程 / 日志 / 设置**。

- **双主题**：日间（樱花粉白紫，沿用 1.x 配色）/ 夜间（深色紫青，默认），切换后全局持久化
- **长按检测时间**：在概览页拖动滑块或直接输入（100–2000ms）
- **按键列表**：在按键页点「＋ 添加按键」新增一行；点击键位按钮可捕获单键或组合键（Ctrl/Shift/Alt/Win + 主键）。每行可选触发模式：
  - 保持：到达阈值后持续按住该键，松开右键才松开
  - 点按·单次：到达阈值瞬间按一下即松开，只触发一次
  - 点按·连发：到达阈值后按「连发间隔」重复点击，按住期间持续，松开结束
  - 每行还可设置**行级延迟**（到达阈值后再等指定毫秒触发）和**组合键输出**；相同键位会在页面顶部提示重复
- **测试**：在概览页点「开始测试」实时显示右键是否按下、当前触发的键位及模式
- **配置方案**：概览页可新建多套方案并一键切换；设置自动保存到所选文件夹的 `<方案名>.ini`
- **全局热键**：设置页点击热键按钮后按下组合键即可更换（默认 Ctrl+F12），随时切换联动开关
- **开机自启**：设置页开关会创建/删除名为 RMBCK 的计划任务（需管理员权限，登录时启动，不弹 UAC）
- **触发日志**：日志页记录本次运行期间的触发（最多 1000 条），可导出 CSV 或清空；记录不写入磁盘
- **其他配置**：进程切换提示、彩蛋、HUD、热键提示四类弹窗开关，修饰键屏蔽、随机抖动防检测等

## 自定义图标素材
前端图标位于 `web/assets/`，编译期嵌入 exe；替换后必须运行 `build.bat` 重新编译，只改根目录同名副本不会生效。

| 文件 | 用途 | 格式与尺寸 |
|------|------|-----------|
| `icon.ico` | exe 文件图标（资源管理器中显示） | ICO，256×256 |
| `web/assets/window.ico` | 托盘图标 | ICO，256×256 |
| `web/assets/icon.png` | 界面品牌图标、弹窗小图标 | PNG，64×64 透明底 |
| `web/assets/iconf1~4.png` | 头部 logo 备用帧素材（当前界面使用静态 `icon.png`） | PNG，建议 128×128 正方形透明底 |

根目录的 `window.ico`、`icon.png`、`iconf*.png` 是 `web/assets/` 对应文件的副本，便于替换对照；实际生效的是 `web/assets/` 下的文件。资源缓存键含内容哈希，重新编译后无需手动清缓存。

## 从源码构建
`build.bat` 使用 Windows 内置 C# 编译器 + `lib/` 下的 WebView2 SDK，无需安装开发环境；双击或命令行运行即可生成 exe。前端资源在 `web/`，编译期自动嵌入 exe。`test.bat` 用于编译并运行纯逻辑测试。
