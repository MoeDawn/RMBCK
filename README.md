# 右键长按联动器（RMBCK）

按住鼠标右键超过设定的检测时间后，自动触发你勾选的键盘键位。

## 使用
1. **双击 `RMBCK <版本号>.exe` 即可运行**
2. 首次运行若出现"已保护你的电脑"提示，点「更多信息」→「仍要运行」
3. 程序**需要管理员权限**：启动会弹出 UAC 授权框，点「是」（用于向管理员权限运行的进程注入按键）
4. 要求 Windows 10（1903+）或 Windows 11
5. **全局热键 Ctrl+F12**：随时切换联动开关（游戏内也生效）；关闭窗口默认最小化到托盘，退出请用托盘图标右键菜单

### 联动目标进程（可选）
「联动目标进程」下拉框可选择某个进程：选中后**仅当该游戏窗口在前台时**才触发联动，避免在桌面/其他程序误触发；点「清除」恢复不限制

## 配置
- **长按检测时间**：拖动滑块调节（100–2000ms）
- **按键列表**：点「＋ 添加按键」新增一行，键位从下拉列表选择；每行可选触发模式：
  - 保持：到达阈值后持续按住该键，松开右键才松开
  - 点按·单次：到达阈值瞬间按一下即松开，只触发一次
  - 点按·连发：到达阈值后按「连发间隔」重复点击，按住期间持续，松开结束
- **测试**：点「开始测试」实时显示右键是否按下、当前触发的键位及模式
- **配置方案**：可新建多套方案，一键切换；设置自动保存到所选文件夹的 `<方案名>.ini`
- **其他配置**：如延迟抖动、禁用修饰键、禁用提示弹窗、动态图标开关等，可按需调整

## 自定义图标素材
所有图标文件均可自行替换，替换后运行 `build.bat` 重新编译即可：

| 文件 | 用途 | 格式与尺寸 |
|------|------|-----------|
| `icon.ico` | exe 文件图标（资源管理器中显示） | ICO，256×256 |
| `window.ico` | 窗口/任务栏图标 | ICO，256×256 |
| `icon.png` | 弹窗小图标、静态头像 | PNG，64×64 透明底 |
| `iconf1~4.png` | 头部 logo 动画帧 | PNG，建议 128×128 正方形透明底 |

动画帧可增删：按 `iconf1.png`、`iconf2.png`… 顺序编号，程序自动加载全部帧循环播放；不足 2 帧时自动退回静态图标。

## 从源码构建
 `build.bat`（Windows 内置 C# 编译器，无需安装开发环境），双击或命令行运行即可生成 exe
