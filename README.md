# 右键长按联动器（RMBCK）

按住鼠标右键超过设定的检测时间后，自动触发你勾选的键盘键位。

> 📋 版本更新记录见 [CHANGELOG.md](CHANGELOG.md)

## 使用
1. 双击 `RMBCK <版本号>.exe` 即可运行，**无需安装任何软件**。
2. 首次运行若出现"已保护你的电脑"提示，点「更多信息」→「仍要运行」。
3. 程序**需要管理员权限**：启动会弹出 UAC 授权框，点「是」。（用于向管理员权限运行的游戏注入按键，如暗区突围无限）
4. 要求 Windows 10（1903+）或 Windows 11。

### 联动目标进程（可选）
「联动目标进程」下拉框可选择某个游戏进程：选中后**仅当该游戏窗口在前台时**才触发联动，避免在桌面/其他程序误触发；点「清除」恢复不限制。

## 配置
- **长按检测时间**：拖动滑块调节（100–2000ms）。
- **按键列表**：点「添加键」新增一行；键位列可下拉选择或直接输入；每行可选触发模式：
  - 保持：到达阈值后持续按住该键，松开右键才松开。
  - 点按·单次：到达阈值瞬间按一下即松开，只触发一次。
  - 点按·连发：到达阈值后按「连发间隔」重复点击，按住期间持续，松开结束。
- **测试**：点「开始测试」实时显示右键是否按下、当前触发的键位及模式。
- **配置文件位置**：默认在程序所在目录；点「浏览…」可自选文件夹，设置自动保存到该处 `config.ini`。
- **联动开关**：可整体启用/停用联动（停用时仍可用测试功能查看状态）。

## 重新编译（可选）
双击 `build.bat` 即可用系统自带的 C# 编译器重新生成 exe，无需安装任何环境。
